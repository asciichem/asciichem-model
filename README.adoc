= asciichem-model

The AsciiChem contract repository: the implementation-independent
semantic model shared by every implementation.

[IMPORTANT]
====
This repository is NOT a rubygem. The Ruby runtime model lives in
the https://github.com/asciichem/asciichem-ruby[asciichem gem]
(`AsciiChem::Model::*`); the TypeScript implementation vendors the
generated types. This repository is the source of truth — LUTAML
model definitions, versioned JSON Schemas, examples, and the
generated types — documented on
https://asciichem.org/models/[asciichem.org/models].
====

== Layout

[cols="1,3"]
|===
|`models/asciichem/*.lutaml` | LUTAML class definitions (the authoring form)
|`schemas/v1/*.yaml` | JSON Schemas (draft 2020-12), one per node type, repo-pinned `$id`s
|`schemas/v1/examples/` | Numbered positive examples + `99-*` must-reject negatives
|`schemas/v1/types/` | Generated TypeScript types (never edit by hand)
|`scripts/` | Maintainer tooling: type generator, example validator
|===

== Maintainer tooling

....
bundle install
bundle exec scripts/generate-types-from-schemas   # regenerate TS types
bundle exec scripts/validate-examples             # validate examples against schemas
....

CI runs both and fails on drift. Consumers vendor from tags: the gem
checks in `spec/schemas` (refreshed by
`scripts/update-model-schemas.sh`), asciichem-ts vendors the types
(`scripts/update-model-types.sh`).

== Versioning

Additive changes bump the patch line within v1; adding a bond kind is
a minor bump (the enum is a closed contract). Breaking changes open a
`v2` directory and never mutate v1.

Historical note: this repository shipped as the `asciichem-model`
rubygem through 0.3.4 (validators for Ruby consumers); 2026-09-12 it
became a pure contract repository (TODO.impl 59).
